# Introduction to Windows Driver Vulnerability Analysis
This workshop teaches Windows kernel concepts and driver analysis, with a focus on vulnerable IOCTLs. Topics include Windows OS architecture, memory management, kernel vs. user mode execution, kernel data structures, and Windows driver analysis techniques. The workshop culminates in a guided exercise analyzing a vulnerable driver to identify the DriverEntry function, device and symbolic link creation, the driver's dispatch function, and vulnerable IOCTLs.

## Prerequisites  
What to Bring: a laptop able to run IDA Free (recommend minimum 16GB RAM).
